# 验收记录

2026 年 11 月 18 日，Linux x86-64，Node.js 24.22.1。开发、构建、自动化验收均使用仓库内锁定的依赖。

## 功能验证

| 路径 | 实测结果 |
| --- | --- |
| OpenAI 官方语言服务 | Agents SDK 经 Responses API 请求 gpt-6.2-sol。返回的局部 OpenUI 声明通过解析、合并和场景校验，角色控制器 speed 从 260 变为 180。 |
| OpenAI 官方生图服务 | 独立 Images API 客户端请求 gpt-image-2.6-sunburst，获得 833755 字节的 PNG，通过文件头与尺寸校验。 |
| 两种兼容接口 | 本地协议服务覆盖 Responses、Chat Completions、独立地址和凭据、正常结束、输出截断和同事务重放。 |
| 游戏运行 | 平台跳跃、俯视收集均通过计分、到达终点、锁定输入、重开恢复测试。另测薄墙连续碰撞、时钟、实例身份和生命周期。 |
| 编辑事务 | 任意分块、悬空引用、非法物理变换、来源范围、过期版本、序号缺口和哈希不符均有用例。局部改色保留已拾取物体的销毁状态。 |
| Chromium 端到端 | 使用真实浏览器、WebGL、IndexedDB、Agents SDK 和测试模型服务。生成关卡，操作角色拾取并通关，暂停选中外观节点，提交改色与速度补丁，加入生图素材，导出项目，刷新，再由包恢复。检查素材、标注、速度和颜色。 |
| 小屏布局 | 浏览器宽度 390 px 下验证画布可见，页面无横向溢出。 |

## 性能采样

参考环境为 Intel Xeon Platinum 8573C、无头 Chromium 153.0.8010.0、软件 WebGL、设备像素比 1。基准使用 1920 × 1080 逻辑画布、500 个可见图形、100 个静态碰撞体、30 个移动角色和 100 个触发区。源码为 117798 字节，无外部纹理下载。

预热 30 帧后保留 120 个帧间隔。角色按固定输入改变方向。草稿预览和补丁提交各采样 10 次，每次修改 20 条声明。预览时间包含草稿构建和渲染提交，未计入屏幕扫描输出。提交时间包含校验、语句合并和运行世界更新。IndexedDB 异步写盘单独处理。

| 测量项 | p95 | 设计目标 |
| --- | ---: | ---: |
| 稳态帧间隔 | 16.7 ms | ≤ 16.7 ms |
| 单步模拟 | 0.6 ms | ≤ 4 ms |
| 渲染提交 CPU 时间 | 7.0 ms | 记录值 |
| 草稿预览 | 47.9 ms | ≤ 100 ms |
| 20 条语句的补丁提交 | 50.4 ms | ≤ 100 ms |

同机负载和软件光栅化设置会影响帧间隔。可用 npm run benchmark 在目标桌面与浏览器重新测量。

## 可恢复边界

- GitHub 版本控制覆盖系统、设计、示例、锁文件和测试。浏览器保存当前作者项目。跨设备恢复使用导出的 ZIP。
- 服务端保存最近完成的事务以支持当前进程内的重放。已提交的 txId 随浏览器项目历史保存。进程重启后中断的生成需要重新发起。
- 当前输入语言是设计中的受限 game2d/1.0。复杂刚体、网络多人游戏和完整 Godot 项目导入属于后续范围。
